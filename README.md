## 🚀 Getting Started

### Prerequisites
- Node.js 18+ 
- Angular CLI 19+

### Installation
```bash
cd website
npm install
```

### Development
```bash
npm start
# Serves at http://localhost:4200
```

### Production Build
```bash
npm run build:prod
# Outputs to dist/ folder
```
